# 什么是数据结构？

## 🧠 一句话理解

> **数据结构 = 组织数据的方式**

就像你的衣柜：

- 叠放（栈）
- 挂放（队列）
- 按标签分类（字典）
- 按大小排列（二叉搜索树）

每种方式都有它的优缺点，适用于不同的场景。

## 🤔 为什么要学数据结构？

```
没有数据结构：                       有了数据结构：
const item1 = 'a'                    const stack = new Stack()
const item2 = 'b'                    stack.push('a')
const item3 = 'c'                    stack.push('b')
// 怎么找？怎么删？                  stack.pop()    // 轻松弹出
// 一团乱麻                           stack.peek()   // 随时查看
```

**学数据结构的三个理由：**

1. **写更高效的代码** — 选对数据结构，性能提升 1000 倍
2. **面试必考** — 大厂面试 90% 会考察数据结构和算法
3. **理解底层原理** — 数组、对象这些 JS 内置结构背后都有数据结构的思想

## 🎯 怎么学效果最好？

1. **先看概念** — 每个章节都有现实类比，建立直觉
