# ⚡ LRU 缓存

> **满时淘汰最久未使用的项目** — 就像办公桌上推开旧文件放新文件

---

## 📖 概念

### 现实类比

<div class="analogy-box">

**📚 办公桌**：桌上只能放 3 本书。需要新书时从书架上拿（慢），放桌上。桌子满了，就移除最久没碰的那本。

</div>

### LRU = 哈希表 + 双向链表

| 操作                | 方式                           | 时间 |
| ------------------- | ------------------------------ | :--: |
| **get(key)**        | 查 HashMap，节点移到头部       | O(1) |
| **put(key, value)** | 存在则更新移头部；满则淘汰尾部 | O(1) |

---

## ⏱ 复杂度

| 操作 | 时间 |
| ---- | :--: |
| get  | O(1) |
| put  | O(1) |

---

## 💡 决策指南

| 场景                       | 推荐                  |
| -------------------------- | --------------------- |
| 需要 O(1) 操作且有内存上限 | ✅ LRU 缓存           |
| 项目有不同过期时间         | ❌ 用 LFU 或 TTL 缓存 |
| 简单的缓存，不需要淘汰     | ❌ 用普通 Map         |
