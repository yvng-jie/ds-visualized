#  跳表 Skip List

> **多层链表实现快速搜索** — 就像高速路加普通路

---

##  概念

### 现实类比

<div class="analogy-box">

** 高速路 vs 普通路**：穿城先上高速（少停），再下到普通路。跳表也一样 — 上层"跳过"很多节点快速定位，下层精确定位。

</div>

### 复杂度

| 操作 |   平均   | 最差 |
| ---- | :------: | :--: |
| 搜索 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

---

##  决策指南

| 场景                     | 推荐              |
| ------------------------ | ----------------- |
| 需要 O(log n) 且代码简单 |  跳表           |
| 需要最差情况保证         |  用平衡 BST     |
| 并发访问                 |  跳表（锁友好） |
